# Noor Haute Couture — Luxury Pakistani Boutique

The digital flagship for bespoke Pakistani bridal couture, formal wear, and luxury pret. Preserving centuries of zardozi, tilla, dabka, and raw silk traditions for modern global couture.

---

## 🌟 Pages & Architecture

- **`index.html`** — **Home / Flagship Showcase**: Editorial hero banner, signature pieces carousel, silhouette taxonomy, Lahore atelier heritage, client testimonials, and newsletter invitation.
- **`collection.html`** — **The Festive & Formal Collection**: Catalog view featuring filtering options, sorting, artisan badges, and quick views.
- **`product.html`** — **Shehnai Peshwas Product Detail**: Interactive editorial gallery with zoom magnifier, artisan craft certifications, size guide modal, installment pricing widget, and heirloom packaging details.
- **`consultation.html`** — **Bespoke Salon & Bridal Concierge**: Bespoke appointment booking, worldwide video fittings, and measurement concierge.

---

## 🎨 Design System

- **Typography**: Playfair Display (editorial headlines) & Plus Jakarta Sans (body, micro-labels)
- **Palette**:
  - Imperial Emerald (`#003526`)
  - Antique Gold (`#795902` / `#fdd275`)
  - Muted Ivory (`#fcf9f8`)
- Built with **Tailwind CSS**, **Google Fonts**, and **Google Material Symbols**.

---

## 🚀 Running Locally

To run this website locally using Python's built-in HTTP server:

```bash
# In the project directory:
python -m http.server 8000
```

Then visit: [http://localhost:8000](http://localhost:8000)
